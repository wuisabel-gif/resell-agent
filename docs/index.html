The case

A wardrobe accumulates value it rarely realises.

The bag out of rotation, the barely-worn coat, the watch kept in a drawer — each is worth real money to the right buyer. Selling it well is its own discipline.

The price

The honest market figure, drawn from real comparables — not a lowball, not a guess.

The words

A listing that reads considered rather than eager, in the voice each platform rewards.

The placement

On eBay and Poshmark, where the buyers for these pieces are already looking.

The process

A single reading, then a placement

Everything up to placement only reads — nothing is posted, nothing on an account changes. The draft is yours to review before a piece is ever listed.

Procedure

Running a piece, beginning to end

Steps one through three are prepared once. Four through six repeat for each piece.

1

Install & build

Node 22 or later. The build compiles to dist/; rebuild after any change.

npm install && npm run build
2

Configure keys

Copy the example environment and provide your eBay and Anthropic keys. Keep EBAY_ENV=sandbox until you are ready to list in earnest.

cp .env.example .env # then fill in the keys
3

Authorise placement to list only

Pricing requires nothing further. To place a listing, authorise a user token once and create your business policies — the full sequence is in the README.

4

Draft the listing

A clean frontal image and the label read best. Add --clean to lift the piece from its background — a cleaner reading, and a squared image ready to list.

npm run draft -- --photos front.jpg,label.jpg --clean
5

Review the draft

The considered step. Read draft.md before it goes anywhere and confirm:

  • The price — a range from comparables, framed as a point of entry. A thin sample deserves your own eye.
  • Condition & notes — the reading is candid by design; confirm it caught the real wear.
  • Category & specifics — resolved for you; correct anything that reads wrong.
  • Titles — eBay dense with the terms buyers search, Poshmark warmer.
6

Place it

Host the images at public URLs (eBay retrieves them), and the category carries from the draft. Poshmark stays by hand — the tool writes a listing to place, and never posts there for you.

The craft

How the parts that matter work

PriceTrimmed comparables
The extreme tenth on each side is trimmed, then the median taken. Absent sold data it draws on active asking prices, discounted — always given as a range, never false precision.
AttributionRead from the piece
House, material, colour, closure, and condition are read from the photographs. It won't invent what it can't see — measurements, for one, are left for you to add.
The cutout--clean
The background is lifted and the piece squared and centred — a cleaner reading, and an image ready to list on a white ground.
PlacementeBay Sell API
Category and item specifics are resolved for you; the listing is composed and, only on your word, published. Poshmark is written but placed by hand.
In candour

What it won't do

  • It won't authenticate. It reads what's visible; it does not verify a house's mark. For high-value pieces, authenticate before you list.
  • It won't invent measurements. A photograph can't be measured — those fields are left for you to complete.
  • It won't host your images. The cutout is produced; eBay needs a public URL, so you host it.
  • It won't post to Poshmark. The copy is written; placing it there is yours.
  • Placement is the one irreversible step. The draft is the gate, and it runs only when you run it.
