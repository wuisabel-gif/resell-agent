B

Procedure

Operations 1–3 are one-time setup. Repeat 4–6 for every item.

1

Install & build

Node 22+. The build compiles TypeScript to dist/; rebuild after any code change.

npm install && npm run build
2

Configure keys

Copy the example env and fill in your eBay app keys and Anthropic key. Keep EBAY_ENV=sandbox until you're ready to list for real.

cp .env.example .env
# EBAY_CLIENT_ID, EBAY_CLIENT_SECRET → developer.ebay.com
# ANTHROPIC_API_KEY                  → console.anthropic.com
3

Authorize posting only to publish

Pricing needs nothing more. To publish, authorize a user token once and create your business policies (full walk-through in the README).

npm run auth-url                 # open URL, approve, copy ?code=
npm run auth-exchange -- <code>   # paste refresh token into .env
4

Draft the listing

A clean front shot plus the brand/size tag reads best. Add --clean to strip photo backgrounds first — better attribute reads, and the .clean.png files are listing-ready.

npm run draft -- --photos front.jpg,back.jpg,tag.jpg \
  --notes "small stain on left cuff" --clean
5

Review draft.json

This is the checkpoint. Read it before publishing and confirm:

  • Price basis — sold comps, or discounted active asks? A thin sample means eyeball it.
  • Condition & flaws — the model is told to be honest; check it caught real wear.
  • Category & specifics — auto-resolved; fix the category if it looks off.
  • Titles — eBay keyword-dense (≤80 chars), Poshmark warmer.
6

Publish to eBay

Host your images at public URLs first (eBay pulls them). Category comes from the draft — --category is now just an override. Poshmark is copy-only: the tool writes a paste-ready listing but never auto-posts there.

npm run post -- --draft draft.json \
  --images https://host/1.jpg,https://host/2.jpg \
  --location my-loc --fulfillment <id> --payment <id> --return <id>

D

Internals

How the parts that matter actually work.

Pricingtrimmed stats

Trims the extreme 10% each side, then takes the median of sold comps. With no sold data it falls back to active asks discounted 15% — quoted as a range, not false precision.

Taxonomyauto category

The draft resolves the eBay leaf category from the title and fills item specifics (Brand, Size, Color…) from the extracted attributes — the fields eBay weights in search. No manual --category.

Clean--clean flag

Optional background removal to a transparent PNG — cleaner input for the vision read, and eBay composites transparent images onto white for you.

Sold compsdormant · gated

The real Marketplace Insights call is written but switched off. Once eBay approves the scope, set EBAY_INSIGHTS=1 — sold-comp pricing turns on with no code change.

E

What it won't do

×

No sold-comp pricing yet — until Marketplace Insights is approved, pricing leans on active asks. Treat thin samples with suspicion.

×

It doesn't host images — --clean makes the PNG; eBay needs a public URL, so you host it.

×

Poshmark is manual — copy is generated; posting there is on you (no public API).

×

Sandbox gaps — some taxonomy calls are production-focused; expect blanks on EBAY_ENV=sandbox.

×

Publishing is the one irreversible step — the draft is the gate, and post only runs when you run it.
